# Repo Analysis Policy

只在 prompt 第 8 层确实有目标仓库可分析时读取本文件。

## 最低检查面

至少检查以下内容：

- 根目录结构
- README 或等价入口文档
- 关键配置文件
- 与目标概念最相关的模块、脚本或工作流文件

## 判断要求

- “哪些文件体现了这个概念”必须给出真实路径。
- “有意识使用还是无意暗合”只能基于仓库证据做谨慎判断；证据不足时明确写“无法判断”。
- “做得好 / 差距 / 风险”必须对照 prompt 第 3 层与第 7b 层，而不是泛泛点评。

## 禁止事项

- 不要因为第 8 层存在，就强行把不相关仓库写成案例。
- 不要在没读代码的情况下给出实施建议。
